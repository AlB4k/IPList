# IPList для Windows

Windows-версия IPList 1.4.0 предназначена для Windows 10 22H2 и Windows 11 (win-x64). Публикуемый пакет будет self-contained ZIP и не требует установленного .NET. Данные хранятся в `%LOCALAPPDATA%\IPList`; файлы `.vpn` не поддерживаются, исходные `.conf` не изменяются.

На текущем этапе Core и минимальный WPF-каркас собраны в отдельной ветке. Финальный ZIP публикуется только после прохождения Windows CI и ручной проверки на чистых Windows 10 и 11.
